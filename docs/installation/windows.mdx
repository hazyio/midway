---
title: "Windows"
description: "Install the Midway CLI on Windows with PowerShell"
---

Run this in PowerShell to download and run the installer:

```powershell
Invoke-RestMethod https://raw.githubusercontent.com/hazyio/midway/main/install.ps1 | Invoke-Expression
```

The installer supports Windows x86_64. It downloads the matching release, installs `midway.exe` under `%LOCALAPPDATA%\Programs\Midway`, and adds that directory to your user `PATH`. Open a new terminal if `midway` is not available in the current one.

ARM64 Windows does not currently have a prebuilt release. The installer reports this and directs you to [build with Cargo](/installation/cargo).

To choose another install directory, set `INSTALL_DIR` before running the installer:

```powershell
$env:INSTALL_DIR = "$HOME\bin"
Invoke-RestMethod https://raw.githubusercontent.com/hazyio/midway/main/install.ps1 | Invoke-Expression
```

The latest GitHub release must include a `midway-<rust-target>.zip` asset containing `midway.exe`.

To check for and install an update, download the script and pass `update`:

```powershell
$installer = Join-Path $env:TEMP "install-midway.ps1"
Invoke-WebRequest https://raw.githubusercontent.com/hazyio/midway/main/install.ps1 -OutFile $installer
& $installer update
Remove-Item $installer
```

Update mode checks the `midway.exe` found on your `PATH`. If `INSTALL_DIR` is set, it checks and updates `midway.exe` in that directory instead. If the installed version matches the latest release, the installer reports that Midway is up to date and exits without replacing it.

Verify the installation:

```powershell
midway --version
```
