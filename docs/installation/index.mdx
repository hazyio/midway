Choose an installation method:

- [Install with Cargo](/installation/cargo)
- [Install a release binary](/installation/release-binary)
- [Install on Linux and macOS](/installation/shell-script)
- [Install on Windows](/installation/windows)

Prebuilt release binaries are available for Linux x86_64, Windows x86_64, and Apple Silicon macOS (aarch64). If you use ARM64 Windows, ARM64 Linux, or Intel macOS (x86_64), install from source with [Cargo](/installation/cargo).

After installation, verify that the CLI is available:

```bash
midway --version
```
