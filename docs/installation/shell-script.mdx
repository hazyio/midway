---
title: "Shell script"
description: "Install the Midway CLI with the shell installer"
---

The installer detects your operating system and architecture, downloads the latest matching release binary, and installs it to `~/.local/bin`.

Prebuilt releases are available for Linux x86_64 and Apple Silicon macOS (aarch64). ARM64 Linux and Intel macOS (x86_64) are not currently packaged; the installer directs those systems to [install with Cargo](/installation/cargo).

```bash
curl -fsSL https://raw.githubusercontent.com/hazyio/midway/main/install.sh -o install.sh
sh install.sh
```

Set `INSTALL_DIR` to install somewhere else. The installer expects a `midway-<rust-target>.tar.gz` release asset containing the `midway` executable.

To check for and install an update, run the installer with the `update` argument:

```bash
sh install.sh update
```

Update mode checks the version of `midway` found on your `PATH`. If `INSTALL_DIR` is set, it checks and updates `midway` in that directory instead. If the installed version matches the latest release, the installer reports that Midway is up to date and exits without replacing it.

Verify the installation:

```bash
midway --version
```
