---
title: "Shell script"
description: "Install the Midway CLI with the shell installer"
---

The installer detects your operating system and architecture, downloads the latest matching release binary, and installs it to `~/.local/bin`.

```bash
curl -fsSL https://raw.githubusercontent.com/hazyio/midway/main/install.sh -o install.sh
sh install.sh
```

Set `INSTALL_DIR` to install somewhere else. The latest GitHub release must include a `midway-<rust-target>.tar.gz` asset containing the `midway` executable.

Verify the installation:

```bash
midway --version
```
