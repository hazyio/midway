---
title: "Release binary"
description: "Download and install a prebuilt Midway CLI binary"
---

1. Open the [Midway releases](https://github.com/hazyio/midway/releases) page.
2. Download the archive matching your operating system and architecture. Windows releases use ZIP archives; Linux and macOS releases use `.tar.gz` archives.
3. Extract the archive and move the `midway` executable to a directory on your `PATH`.

Verify the installation:

```bash
midway --version
```
