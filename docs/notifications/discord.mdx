---
title: "Discord notifications"
description: "Connect Midway to a Discord channel with a webhook"
---

## Create a Discord webhook

1. Open the channel where Midway should post and go to **Edit Channel**.
2. Open **Integrations**, select **Webhooks**, then create a webhook for the channel.
3. Copy the webhook URL.

## Add the webhook to Midway

Run the Midway setup command and paste the webhook URL when prompted:

```bash
midway init
```

By default, Midway sends notifications to all configured methods. To restrict delivery, define `notification.send_to` and include `Discord`; configured methods left out of the list will not receive notifications. With `pick_from: All`, Midway sends through every method listed there:

```yaml
notification:
	send_to:
		- Discord
	pick_from: All
```

`pick_from` can further select a subset of the methods in `send_to` for each notification.

The current setup prompt accepts one webhook URL per configuration.

You can also add the webhook URL directly to `midway.yaml` under `tokens.discord`:

```yaml
tokens:
	discord: "https://discord.com/api/webhooks/WEBHOOK_ID/WEBHOOK_TOKEN"
```
