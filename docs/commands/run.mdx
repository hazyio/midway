---
title: "Run a command"
description: "Run a process and get notified when it finishes"
---

Use `midway run` followed by the program and its arguments:

```bash
midway run cargo build --release
```

Midway starts the program directly and waits for it to exit. Arguments are passed to the program as provided; Midway does not interpret shell operators, pipes, or variable expansion. To use shell features, invoke a shell explicitly, for example `midway run sh -c 'cargo build && echo done'` on Linux or macOS.

When `command_notifications.notify_while_running` is enabled, Midway sends one "still running" notification when the command starts. After the process exits, it sends a completion notification if the command ran for at least `command_notifications.minimum_runtime_for_completion_notification_seconds` (10 seconds by default). The completion notification reports whether the command succeeded or failed; `run` does not send periodic updates.

Midway reads `midway.yaml` from the current working directory. Select another config file with `--config`:

```bash
midway --config ./config/midway.yaml run cargo test
```

See [configuration](/config) to set the duration threshold and notification destinations.
