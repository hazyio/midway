---
title: "Run a command"
description: "Run a process and get notified when it finishes"
---

Use `midway run` followed by the program and its arguments:

```bash
midway run cargo build --release
```

## Arguments

| Argument              | Required | Description                                                                                                                                         |
| --------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<COMMAND> [ARGS]`    | Yes      | Program to run and its arguments. Midway passes these directly to the program; it does not interpret shell operators, pipes, or variable expansion. |
| `-c, --config <PATH>` | No       | Read configuration from this path instead of `midway.yaml` in the current directory.                                                                |

To use shell features, invoke a shell explicitly, for example `midway run sh -c 'cargo build && echo done'` on Linux or macOS.

When `command_notifications.notify_while_running` is enabled, Midway sends a "still running" notification every `command_notifications.running_notification_interval_seconds` seconds while the command is running (15 seconds by default). The first notification is sent after that interval, not at launch. After the process exits, Midway sends a completion notification if the command ran for at least `command_notifications.minimum_runtime_for_completion_notification_seconds` (10 seconds by default). The completion notification reports whether the command succeeded or failed.

Midway reads `midway.yaml` from the current working directory by default. Select another config file with `-c` or `--config`:

```bash
midway --config ./config/midway.yaml run cargo test
```

See [configuration](/config) to set the duration threshold and notification destinations.
