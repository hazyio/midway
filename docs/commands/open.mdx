---
title: "Open Midway"
description: "Run commands in Midway's interactive shell"
---

Run `midway open` to start an interactive shell:

```bash
midway open
```

Midway reads `midway.yaml` from the current working directory by default. Use `-c` or `--config` to select another configuration file:

```bash
midway --config ./config/midway.yaml open
```

Enter a command at the Midway prompt to run it. The shell supports command history and the built-ins `cd` and `exit`; Ctrl+D also exits. Enter `midway` to print a confirmation that you are in the Midway environment. The command `rm -rf /` is blocked.

When `command_notifications.notify_while_running` is enabled, Midway sends a "still running" notification every `command_notifications.running_notification_interval_seconds` seconds while a command is running (15 seconds by default). The first notification is sent after that interval, not when the command starts. After the command exits, Midway sends a completion notification if it ran for at least `command_notifications.minimum_runtime_for_completion_notification_seconds` (10 seconds by default). See [configuration](/config) to change these values and [notification guides](/notifications/local) to set up destinations.
