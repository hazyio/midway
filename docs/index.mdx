title: "Introduction"
description: "Get notified when your commands finish running."
---

Midway runs commands and can send periodic notifications while they run, then a completion notification when they finish. Running notifications are enabled by default and repeat every 15 seconds; completion notifications are sent for commands that run at least 10 seconds. Configure `command_notifications` in `midway.yaml` to adjust these settings. Send notifications to your desktop or configure a messaging service.

## Quick start

Install Midway with Cargo, or choose [another installation method](/installation/index), then create a configuration and run a command:

```bash
cargo install midway-cli
midway init
midway run cargo build
```

To send a notification directly:

```bash
midway send-text --message "Build finished"
```

## AI agent notifications

Use your coding agent's lifecycle hooks to call `midway send-text` when an agent finishes or needs approval. Guides for Claude Code, Codex CLI, GitHub Copilot, Gemini CLI, Antigravity CLI, OpenCode, and Cursor are in the [agent documentation](/agents/index).

Use `--background` in hooks so the notification still sends if the agent or hook process is interrupted.

By default, Midway selects all notification methods. Set `notification.send_to` in `midway.yaml` to restrict the methods, and use `pick_from` to control how many listed methods receive each notification.
