title: "Introduction"
description: "Get notified when your commands finish running."
---

Midway runs commands and sends a completion notification after a command exits if it ran longer than a configured threshold. The default threshold is 10 seconds; change `notify_after.minimum_send_after` in `midway.yaml` to adjust it. Midway does not currently send progress notifications while a command is still running. Send notifications to your desktop or configure a messaging service.

## Quick start

Install Midway with Cargo, or choose [another installation method](/installation/index), then create a configuration and run a command:

```bash
cargo install midway-cli
midway init
midway run cargo build
```

To send a notification directly:

```bash
midway send-text --message "Build finished"
```

By default, Midway selects all notification methods. Set `notification.send_to` in `midway.yaml` to restrict the methods, and use `pick_from` to control how many listed methods receive each notification.
