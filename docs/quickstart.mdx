Choose one of the installation methods below. The binary downloads are available on the [GitHub releases page](https://github.com/hazyio/midway/releases).

## Prerequisites

- For the Cargo installation, install Rust and Cargo with [rustup](https://rustup.rs/).
- For a release binary, choose an asset that matches your operating system and architecture.

## Install with Cargo

Install the published CLI crate:

```bash
cargo install midway-cli
```

## Install a release binary

1. Open the [Midway releases](https://github.com/hazyio/midway/releases) page.
2. Download the archive for your operating system and architecture, then extract it.
3. Move the `midway` executable to a directory on your `PATH`.

## Install with a shell script

Download `install.sh` from the release assets, then run it:

```bash
sh install.sh
```

## Verify the installation

Confirm that the CLI is available:

```bash
midway --version
```
